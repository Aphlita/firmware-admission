# 锚点候选调研（A2 / A3）

> 目的：为 `configs/anchors.yaml` 的 A2、A3 提供候选，供队长核对后定型。
> 调研时间：2026-11-19。方法：NVD API 2.0 查 CVE → 厂商文件服务器/官网核固件可下载性 → 比对版本是否与公告一致。
> **不写入 anchors.yaml 的原因**：`verified: true` 的语义是“人已核对版本可对且固件可下载”，须由队长确认；本文件只给证据。

## 一、判定门槛（三条全过才算锚点）

1. 固件**公开可下载**（HTTP 200，能取到文件）；
2. 有公开 CVE / 厂商公告；
3. **版本对得上**（公告写的固件版本 = 可下载的固件版本）。

## 二、候选清单

### A2 候选（已完整验证，建议直接采用）：D-Link DCS-960L

| 字段 | 值 |
|---|---|
| vendor / model | D-Link / DCS-960L（REVA） |
| firmware | **1.07.102** |
| download | `https://legacyfiles.us.dlink.com/DCS-960L/REVA/FIRMWARE/DCS-960L_REVA_FIRMWARE_1.07.102.zip` |
| 下载验证（实测） | `HTTP 200`，`Content-Length: 10383663`（≈9.9 MB），`Content-Type: application/x-zip-compressed` |
| CVE（版本精确匹配） | **CVE-2019-17146**：v1.07.102，`tcp`/HNAP 相关**未授权远程代码执行**（Authentication is not required） |
| 其他 CVE（不作锚点依据） | CVE-2024-44589 / CVE-2024-48168 针对 **1.09**，官网目录无该版本 → 不得引用 |
| 可覆盖检查项 | `UNAUTH_COMMAND_EXEC`（E1 预期）、`CRED_DEFAULT_ADMIN_WEB`（HNAP 登录） |
| 证据等级预期 | E1（HNAP 为 HTTP 接口，影子设备内可直接复现请求-响应） |

### A3 候选（需你用浏览器确认下载，二选一）

#### 方案甲：TP-Link Tapo C200（严格符合 docs/00 §4.1「2 摄像头 + 1 路由」）

| 字段 | 值 |
|---|---|
| vendor / model | TP-Link / Tapo C200（V1） |
| 目标 firmware | **≤ 1.1.15**（CVE 明确此范围） |
| 下载入口 | `https://www.tp-link.com/us/support/download/tapo-c200/v1/`（HTTP 200，页面 JS 渲染，抓不到直链） |
| CVE（版本精确匹配） | **CVE-2021-4045**：1.1.15 及以下，`uhttpd`（root）**未授权 RCE** |
| 其他 CVE | CVE-2023-38906（1.1.18）、CVE-2025-14299（V3） |
| 可覆盖检查项 | `UNAUTH_COMMAND_EXEC`、`CRED_DEFAULT_ADMIN_WEB` |
| 需你确认 | 下载页里是否有 **1.1.15 或更低**版本的固件包；若有，把直链发我 |

#### 方案乙：Tenda AC15（谱系价值最高，与 A1 同厂商同接口模式）

| 字段 | 值 |
|---|---|
| vendor / model | Tenda / AC15 |
| 目标 firmware | **V15.03.1.16_multi** 或 **V15.03.05.18_multi** 或 **V15.03.05.19**（三个 CVE 各自对应） |
| 下载入口 | `https://www.tendacn.com/material?keyword=AC15`（HTTP 200，JS 渲染，抓不到直链） |
| CVE（版本精确匹配） | **CVE-2018-5770**：`/goform/telnet` 未授权开启 telnet —— **与 A1 的 `known_issues` 同一接口模式**；**CVE-2018-5767**：V15.03.1.16_multi 未授权 RCE（password 参数）；**CVE-2018-5768**：COOKIE 未授权 RCE；**CVE-2017-16923**：命令注入（US_AC15V1.0BR_V15.03.05.18_multi_TD01） |
| 可覆盖检查项 | `CRED_DEFAULT_SERVICE_LOGIN`（telnet）、`UNAUTH_COMMAND_EXEC` |
| 需你确认 | 下载页是否有上述三个版本之一；有则把直链发我 |
| 额外价值 | 与 A1 构成“同厂商 + 同 `/goform/telnet` 接口模式”，可直接支撑“同族影响面/谱系外推”的叙事与数据 |

## 三、已排除的候选（避免重复踩坑）

| 候选 | 排除原因 |
|---|---|
| **Tenda CP3**（摄像头） | 官网现存 CP3 **V3.2**（页面内实际版本 `V27.5.57`），而 CVE-2023-30351/30352/30353 全部针对 **V11.10.00.2211041355** → **版本对不上** |
| D-Link **DCS-933L** | 官网可下 1.01.07 / 1.02.05 / 1.03.08，而 CVE-2019-10999 针对 **1.05.04**、CVE-2026-2218 针对 up to 1.14.11 → 版本对不上 |
| D-Link **DCS-5222L** | 仅 CVE-2018-18441 一条“DCS 系列泛化”描述，无法锁定具体版本 |
| **Edimax IC-3140W** | CVE-2021-40597（v3.11）/ CVE-2020-26762（v3.07）版本明确，但官网详情页 `404`，下载入口未找到 |

## 四、组合建议与需要你决策的点

| 组合 | 组成 | 优点 | 代价 |
|---|---|---|---|
| **组合一（推荐）** | A1 Tenda O4（路由）+ A2 D-Link DCS-960L（摄像头）+ A3 **Tenda AC15**（路由） | 只有一个锚点需你确认下载；**同族影响面有 2 个真实型号**（Tenda × 2，同为 `/goform/telnet`） | 变成「2 路由 + 1 摄像头」，与 docs/00 §4.1 的「2 摄像头 + 1 路由」不一致；但 `configs/anchors.yaml` 的 A2 备注本就写“优先路由器” |
| 组合二 | A1 Tenda O4 + A2 DCS-960L + A3 **Tapo C200**（摄像头） | 严格符合 §4.1 | 三个锚点里有两个依赖你确认下载；跨厂商更均衡但谱系叙事弱 |

**需你定两件事**：
1. 走组合一还是组合二（即 A3 选 AC15 还是 Tapo C200）；
2. 按你选的那条，把固件页面上能拿到的**版本号与直链**发我，我立刻写进 `configs/anchors.yaml`（`verified: true` 只在拿到直链后才置）。
